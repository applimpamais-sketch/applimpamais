## Dicas de Uso

1. **Para Midjourney:** Adicione `--ar 1:1` para feed ou `--ar 9:16` para stories ao final do prompt
2. **Para DALL-E:** Use os prompts como estão
3. **Textos overlay:** Adicione em ferramenta de edição (Canva, Figma) — IAs não geram texto legível consistentemente
4. **Cores:** Use as paletas indicadas para manter consistência visual entre os criativos
5. **Adaptação:** Troque o número de telefone e links para os reais da RC Limpa Mais antes de publicar
